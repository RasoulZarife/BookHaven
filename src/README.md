
# BookHaven - Online Bookstore

## Project Description

BookHaven is an online bookstore built using React.
It allows users to explore books, search by title or author,
filter books by category, view book details, and manage
their shopping cart.

### Features

- Browse available books.
- Search books by title or author.
- Filter books by category.
- View detailed book information.
- Add books to the shopping cart.
- Increase and decrease book quantities.
- Remove books from the cart.
- Calculate the total price automatically.

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Bootstrap
- React Router
- Git and GitHub
- Vite

## Setup Instructions

1. Clone the repository:

   git clone https://github.com/RasoulZarife/BookHaven.git

2. Navigate to the project folder:

   cd BookHaven

3. Install dependencies:

   npm install

4. Start the development server:

   npm run dev

5. Open the local URL displayed in your terminal.
